Amazon 商品 API 与 Review API 怎么选？先看数据范围，再算采集成本

对比商品页记录与评论页数据，按官方计费单位给出月度估算示例。

2026年11月26日 8 分钟阅读 Pangol Info Team

“我要 Amazon 商品数据和买家评论，是调一个接口还是两个？”先看应用需要保存什么记录。主 Scraper API 面向商品、搜索、类目、卖家和榜单页面；评论页采集是独立产品，有自己的筛选参数和计费方式。若同时需要商品上下文与评论文本，应把两类请求都纳入设计，不要假设商品详情记录等于完整评论数据集。

当前Amazon 数据采集 API 页面列出六类主解析器：商品详情、关键词搜索、类目商品、卖家商品、Best Sellers 和 New Releases。商品详情 API 文档说明 JSON 响应及每次请求 1 Credit 的费率。若要保存的是商品本身的记录，这通常是合适的起点；若下游任务需要逐页评论文本，则还要看评论接口。

独立的Amazon Review API面向评论数据。其文档说明了 `pageCount`、星级筛选、排序、全部款式或当前款式，以及只取含图片或视频评论的选项。开发前请查看实时的Review API 中文文档，确认目标站点和具体字段；接口可用范围与返回值可能取决于所选页面和站点。

关键区别：商品评分摘要不等于评论数据集

商品详情页可能提供适合初筛或监控的汇总字段。对于商品目录、价格监控或第一轮竞品表，这些信息或许已经够用。但如果功能要处理用户实际写下的内容、单条评分、日期、有用性信号或评论媒体，就应把它们建模为评论记录并请求评论接口。不要只凭一个摘要字段就设计完整的情感分析流程。

反过来，评论数据也未必包含应用所需的全部商品属性。若需要把反馈与商品页上下文关联，就明确请求两类数据，并在结果中保留 ASIN 和站点。这样更容易审计商品款式差异、关联错误和后续刷新；但这不保证每个商品页或每次请求都返回所有字段。

把查询范围设清楚。Review API 可选择全部评论或仅含媒体的评论、全部商品款式或当前款式，也能按文档列出的星级过滤。这些代表不同的数据范围，不是无需成本地获取同一份完整语料。先决定你的问题需要广泛探索，还是只要某个特定切片。

按页数估算 Credits，不要按评论条数

当前官方文档列出的费率为：Product Detail JSON 每次请求 1 Credit；Review API 每页 5 Credits。一页不是一条评论。请求页数、筛选范围和实际响应会影响拿到的数据；完成调用后，应以响应里的 pointCost 记录实际扣费。

商品详情 Credits = 商品 JSON 页数 × 1
评论 Credits = 评论页数 × 5
总量 = 商品详情 Credits + 评论 Credits + 其他操作

例如，每月检查 20 个 ASIN，每个商品请求 1 页详情、另取 3 页评论，估算为 20 × 1 + 20 × 3 × 5 = 320 Credits；其他接口、重试和额外刷新尚未计入。Review API 文档允许一次请求的 `pageCount` 为 1–10；若一个商品需要更多页，应把后续请求也算进去。实际用量应与 pointCost 对账，不能拿返回评论条数代替计费单位。

当前产品页面公布每月 60 个免费 Credits。按文档费率，若全部只用于对应接口，最多相当于 60 页商品详情 JSON，或 12 页 Review API；这不代表可以为 60 个商品各采集完整评论历史。更多估算方法可参考月度 Amazon API Credits 规划指南，其中的例子也要按你的接口和刷新节奏重算。

开发前先确定三个输入

  1. 应用实际要保存哪些字段：商品页属性、单条评论，还是两者都要？
  2. 每个账期会请求多少 ASIN 与评论页，多久刷新一次？
  3. 目标 Amazon 站点和评论范围是什么：当前款式还是全部款式、全部评论还是含媒体评论、要筛选哪些星级？

然后在目标站点测试一条有代表性的请求，检查响应结构和 pointCost，再对照实时计价页与账户条款。公开费率和套餐条款可能变化。这是工作量模型，不是套餐推荐，也不保证一定返回某些字段、覆盖范围或固定费用。

结论：决策依赖商品页记录时用 Product Detail；依赖买家逐条反馈时用 Amazon Review API。只有下游功能确实需要两者时再组合，并按当前文档规定的每页费用预算评论工作量。

Amazon Review API 包含在 Product Detail 里吗？评论页采集是单独产品，有独立参数和计费。主 Scraper API 列出的解析器是商品、搜索、类目、卖家、Best Sellers 和 New Releases。

30 页评论需要多少 Credits？按当前公开的每页 5 Credits，30 页为 150 Credits，其他请求另计；实际费用请看响应的 pointCost。

同一个 ASIN 可以同时用两个 API 吗？可以，前提是功能需要商品页上下文和评论记录。按 ASIN 与站点谨慎关联，并分别估算两种计费单位。
